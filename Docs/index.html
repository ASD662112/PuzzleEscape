关于游戏

PUZZLEESCAPE

《PuzzleEscape》是一款第一人称室内解谜逃脱游戏。你在一座封闭的旧宅中醒来，只能借手电筒的微光在走廊、病房与地下室之间摸索：翻找抽屉和柜子，收集钥匙、保险丝、通行卡与四枚封印徽记，解开一扇扇锁住的门。

黑暗中有东西在走动：它会循声赶来，也会追着你穿过楼层。你可以躲进柜子屏住呼吸，也可以放下蜡烛引开它的注意；还可能因为一次奔跑耗尽体力，被它追上。

两张地图、五档难度，从没有怪物的纯粹解谜，到比你还快的恶魔。每一步都在赌：先拿线索，还是先保命。

玩法

01 / 探索

翻遍每一格抽屉

钥匙、保险丝、通行卡、旧日记——线索散落在容器与房间深处，随机刷新让每一次开局都不完全相同。

02 / 潜行

别让它听见你

奔跑、开门、丢下酒瓶都会发出声音。蹲在暗处、关掉手电、躲进柜子，才有机会从它身边溜过去。

03 / 光影

一根蜡烛，六十秒

手电筒与半截蜡烛是唯一的依靠。照亮身边五米，也可以把蜡烛放在地上，当作路标或诱饵。

04 / 难度

从和平到恶魔

开局选定本局难度：和平没有怪物；恶魔的追逐速度比你的奔跑还快十分之一，选定后无法更改。
