# PuzzleEscape · 三层庄园

使用 Unity 2022.3 制作的第一人称室内解密游戏原型。
地图现为 **地表 + 二层 + 地下室** 三层结构：地表由核心区、西翼、东翼、南翼组成，边界约 **68 × 42**，可探索地表面积约为旧版的 2 倍；地下室为 **68 × 28** 的黑暗区域。地表 + 地下室的可探索面积约为旧版的 2.6 倍。

## 地图与房间

- 地表核心区：书房、储藏室、展厅、配电间、餐厅、厨房、会客厅、门厅
- 西翼：藏书室、台球室、酒窖、锅炉房、温室、吸烟室
- 东翼：洗衣房、食品储藏室、工匠间、冰窖、日光房、柴房；东翼走廊尽头是专用电梯厅
- 南翼：旧画廊、标本室、旧剧场、织物间
- 地下室：地下储藏室、地下酒窖、机械间、水泵房、封印密室、仆役旧厅
- 隐藏区域：藏书室地毯暗道通往的地下密室
- 二层：档案室、实验室、卧室、观测室、宴会厅、仆役房、音乐室、客房

地表共 24 个房间，地下室 6 个房间 + 1 个隐藏密室，二层 8 个房间，合计 39 个房间。
东翼可从核心区东侧走廊直接进入；南翼通过西翼/东翼南端走廊进入；地下室入口位于西翼锅炉房的地窖铁门。电梯位于东翼走廊尽头的专用电梯厅，二层对应位置也有同一条电梯厅走廊，不再占用主走廊空间。

## 环境

- Unity **2022.3.62f3c1**
- 渲染管线：Built-in
- 输入：PC 键鼠 + 手机虚拟摇杆/触屏
- 地图已烘焙在 `Assets/Scenes/Main.unity`，编辑模式 Scene 视图可直接查看；材质保存在 `Assets/Art/Materials/Generated`
- 场景根节点包含 `Bootstrap`、`Environment` 与 `PlayerCamera`；`PlayerCamera` 带 `MainCamera` 标签与唯一 `AudioListener`，运行时由 `PlayerFactory` 复用到玩家头下
- 当前 `Environment` 有 **1587** 个直接子对象、**7038** 个 Transform；场景约 **15.9 MB**（真实家具、书本、木箱与装饰摆件已大幅替换程序化零件）
- 共 **119** 个 Light 对象，包含新增东翼、南翼、地下室与上下电梯厅的照明；壁灯、吊灯与烛台现在都会真正发光
- **28** 个可打开抽屉/柜子，**40** 个道具刷新点
- 地下室使用独立的黑暗照明区：进入后降低环境光、加重雾效；离开后恢复正常地表光照

## 摆件精细度与材质

- **程序化纹理**：`Assets/Art/Textures` 下共 15 张 256×256 纹理，覆盖拼花地板、灰泥墙、木纹、地毯、布料、皮革、大理石、瓷釉、金属拉丝、石材斑点，以及 4 幅油画（风景、静物、肖像、夜港）和暗纹桌布。
- **玻璃**：窗户、标本展柜、高脚杯与水晶改为 Standard 透明材质，不再是一块发光的蓝色实体。
- **金属**：铜、金、铁降低金属度并提高基础色，避免在没有反射探针的室内渲染成黑色剪影。
- **吊灯**：金属灯臂、烛杯、接蜡盘、蜡芯、连接吊坠的水晶与真实点光源；吊杆长度贴合 3 米层高，不再穿过天花板。
- **壁灯**：21 盏壁灯各自发出暖色光，走廊与房间边缘不再只靠顶部主灯。
- **餐桌**：高脚杯拆成杯脚、杯柄、杯身与酒液，并补充刀叉、餐巾、内盘沿与三枝金属烛台。
- **绘画**：墙面画框改为「金框 + 卡纸 + 深色内框 + 油画布」，替换原来的纯金色/纯玻璃色块。
- **标本室**：玻璃展柜内放置标本罐与标本，柜顶木冠、木柱、铜标签齐备。
- **洗衣房**：浴盆内加入水面与衣物，洗衣篮增加藤条箍与提手。
- **座椅**：餐椅与扶手椅改为真实 FBX 模型（皮革 PBR 贴图）；程序化座椅保留为模型缺失时的兜底。
- 室内主灯强度提高约 20%、范围提高约 12%，环境光与太阳光略增；地下室仍保持独立的黑暗照明区。

## 打开与运行

1. Unity Hub → `Add project from disk` → 选择本项目根目录 `PuzzleEscape`。
2. 打开 `Assets/Scenes/Main.unity`，点击 Play。
3. 首次打开若场景缺失，可使用菜单：`PuzzleEscape → 重新生成主场景`。

## 怪物 NPC（第一张地图）

- **模型**：用户提供的 OBJ + PBR 贴图放在 `Assets/Art/Models/Monster`；菜单 `PuzzleEscape → 生成怪物 Prefab`（`Assets/Editor/MonsterPrefabBuilder.cs`）会设置贴图导入参数、生成 `MonsterBody` 材质、把模型缩放到 **2.1 m 高**并贴地，输出 `Assets/Resources/Monster/MonsterModel.prefab`。
- **速度**：以玩家步行速度 3.3 m/s 为基准——散步 **1.10 m/s**（1/3），追逐 **2.89 m/s**（7/8）。
- **感知**：视野 16 m、水平 110°；视线用射线检测，墙体、关闭的房门与家具都会遮挡。玩家距离 2.5 m 内不再判定朝向，避免贴脸时丢失目标。
- **状态切换**：玩家进入视野立刻追逐；连续 **5 秒**看不到玩家则停止追逐、回到散步，路径清空重新随机。
- **寻路**：启动时按 1 m 网格分帧采样庄园一层（约 **3140** 个可站立格子，门扇格子视为可通行），使用 BFS 求最短路并做视线平滑。散步模式随机挑选 6–30 m 外的可行走点；追逐模式每 0.45 秒重新规划到玩家所在格子。
- **自动开门**：前进方向 1.7 m 内射线命中 `HingedDoor` 时直接调用 `Open()`，房门 5 秒后照常自动关闭。
- **抓到玩家的跳杀演出**：追逐状态下与玩家水平距离 ≤ **1.5 m** 判定为抓到（`MonsterCatchSequence`）。演出期间玩家控制与怪物 AI 都会暂停：相机从玩家身上脱开，贴到怪物脸前 0.42 m、FOV 从 70° 收到 50°，持续 2 秒并做 1–5 cm 的随机抖动；同时播放程序化跳杀音效（920→110 Hz 下滑尖啸 + 噪声冲击）。随后 0.22 秒黑幕，玩家被送回当前地图出生点、怪物被重置到 25–60 m 外的可行走格子（找不到则回出生位），再 0.55 秒淡入并恢复操作。黑幕由 `UIRoot.SetFadeAlpha` 控制。
- **被抓计数与失败结局**：每次被抓黑屏期间显示「你被抓住了 · 剩余机会 N」（`GameManager.CaughtCount`，上限 3）。**第三次被抓**不再复位，直接进入失败结算面板：标题「你被抓住了」，显示用时与被抓次数，提供「重新开始」按钮；期间玩家控制保持冻结，怪物停止行动。
- **安全兜底**：卡住 1.2 秒会立即换目标；掉到楼梯井或地下室（y < -1.5）会被拉回地面格。
- **限制**：怪物只出现在「谜宅逃脱」地图；被抓计入 3 次上限，没有扣血、难度选择或骨骼动画（模型为静态网格）。

## 解密流程

1. **一层书房**：阅读书桌便签，查看停在 **4:27** 的挂钟，取走书架上的黄铜钥匙。
2. **一层储藏室**：用黄铜钥匙打开抽屉，取得保险丝。
3. **一层配电间**：把保险丝装进电闸，恢复供电。
4. **东翼洗衣房**：打开洗衣柜，取得地下室钥匙。
5. **西翼锅炉房**：在小桌上取得手电筒；用地下室钥匙打开地窖铁门，进入地下室。
6. **地下室机械间**：在工作台取得电梯齿轮。
7. **返回一层**：通过地下室梯子回到锅炉房，到东翼走廊尽头电梯厅的面板安装齿轮，修复电梯。
8. **二层档案室**：在门旁输入 `0427`，进入档案室取得月之徽记。
9. **二层实验室**：按“红 → 蓝 → 绿”启动机关，取得星之徽记。
10. **一层展厅**：取得日之徽记。
11. **地下室封印密室**：取得影之徽记（可在上二层前后自行安排）。
12. **二层西端封印大门**：嵌入日、月、星、影四枚徽记，大门打开后穿过出口通关。

## Unity MCP（开发工具）

项目已接入 MCP for Unity 9.7.1：

- 依赖：`Packages/manifest.json` 中的 `com.coplaydev.unity-mcp`
- 服务端地址：`http://127.0.0.1:8080/mcp`
- 启动服务端：`powershell -ExecutionPolicy Bypass -File Tools/StartUnityMcp.ps1`
- Unity 内菜单：`PuzzleEscape → 连接 Unity MCP`

若客户端显示 `fetch failed`，先确认 8080 端口是否监听，再运行启动脚本；Unity 侧可通过 `Window → MCP For Unity` 查看 Bridge 状态。若服务端已恢复而 Trae 工具列表仍显示不可用，重新连接 MCP 客户端或重启 Trae MCP 面板即可。
